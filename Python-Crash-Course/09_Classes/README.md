### Key Insights and Progress Log.

`Object-Oriented-Programming` is one of the most effective approaches to writing software, we write `classes` that represent real world things and situations, and we create `objects` based on these classes. When we write a class, we define the general behavior that a whole catagory of objects can have. When we create individual objects from a class (`instantiation`), each object (an `instance` of the class, where class is a `blueprint`) is automatically equipped with the general behavior, and we can then give each object whatever unique traits we desire. Here we write classes and create instances of those classes, also we specify the kind of information that can be stored in instances as well as define actions that can be taken with those instances. We also wrote classes that extend the functionality of existing classes, so similar classes can share common functionality and we can do more with less code. We also store our classes in modules and then import classes written by other programmers into our own program files.
