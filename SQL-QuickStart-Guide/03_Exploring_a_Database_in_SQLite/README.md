### Key Insights and Progress Log. 
>In this chapter we familiarize ourselves with the interface of our chosen SQL browser for SQLite: DB Browser.
>First we can start the DB Browser for SQLite application by simply finding the application in the Start menu after installation (which we did in last chapter). Then we can open a database (in our case the sTunes Database) by the `Open Database` icon in the DB Browser default screen and then selecting the database file from the device.
>When the file is opened, the `Database Structure` tab shows the tables contained (by name of tables) in the opened database (In the dropdown button to the left of `Tables(<number of tables>)`). By expanding the arrow to the left of the table name, we are shown the `fields` contained in that table, and beside it we are shown the `data type` of each field eg... `Integer`, `NVARCHAR` (characters or non numeric data) (note that this data type thing here is actually the `metadata`).
>The 'Browse Data` tab beside the 'Database Structure` tab can be used to see the records contained in each table i.e... see the actual data contained in the columns that we could observe in the database structure tab (can use the dropdown next to `Table:` option to switch between tables).
>The `Execute SQL` tab on the same level as the other 2 we studied is where we write our SQL statements. There are 3 main component windows in the execute SQL tab, the `Query Pane`, the `Results Pane` and the `Messages Pane`. We write our Query in the Query pane and press the `play button` above the query pane, and the result of the query is displayed in the Results Pane below it! (not that the play button to the left executes all SQL statements written in the window and the play button to the right executes only the SQL statement that our cursor is on (it executes only 1 statement at a time).). Under the Results Pane is the Messages Pane, which displays informative messages about the query. e.g... no of rows returned from our SQL statement, time taken for the query to run and Error messages if any.
